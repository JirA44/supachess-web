🚀 Déployer ChessNova Pro v2.0

Guide étape par étape pour mettre votre plateforme en ligne

⚡ MÉTHODE SIMPLE (5 MINUTES)

Suivez ce guide pour déployer ChessNova Pro sur Cloudflare Pages via le dashboard web. C'est la méthode la plus simple et la plus fiable!

1
Ouvrir le Dashboard Cloudflare

Cliquez sur le bouton ci-dessous pour ouvrir Cloudflare:

🌐 Ouvrir Cloudflare Dashboard

Si vous n'avez pas de compte, créez-en un (c'est gratuit).

2
Créer un Projet Pages

Une fois connecté:

  • Dans le menu latéral gauche, cliquez sur "Pages"
  • Cliquez sur "Create a project" (ou "Créer un projet")
  • Sélectionnez "Upload assets" (ou "Télécharger des fichiers")
3
Sélectionner les Fichiers

Ouvrez le dossier du projet:

Sélectionnez TOUS ces fichiers et glissez-les dans Cloudflare:

✓ ChessNova_TEACHER_ENHANCED.html
✓ index.html
✓ _headers
✓ _redirects
✓ README.md
✓ wrangler.toml

⚠️ Important: Incluez bien les fichiers _headers et _redirects (ils commencent par underscore)

4
Configurer le Projet

Remplissez les champs:

  • Project name: chessnova-chess
  • Production branch: production (ou master)
  • Laissez les autres paramètres par défaut
5
Déployer!

Cliquez sur "Save and Deploy"

⏱️ Attendez 2-3 minutes pendant que Cloudflare déploie votre site...

☕ Prenez un café pendant ce temps!

🎉 Félicitations!

Votre site sera accessible sur:

https://chessnova-chess.pages.dev

Copiez cette URL et testez-la dans votre navigateur!

🎯 Domaine Personnalisé (Optionnel)

Pour utiliser votre propre domaine (ex: chess.monsite.com):

  1. Dashboard Cloudflare → Pages → chessnova-chess
  2. Onglet "Custom domains"
  3. Cliquez "Set up a domain"
  4. Entrez votre domaine
  5. Cloudflare configure automatiquement le DNS et SSL
